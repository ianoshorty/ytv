# YTV

A YouTube app for a Hisense VIDAA TV, served from GitHub Pages and installed
as a tile. It uses YouTube's official embedded player, which on this TV plays
60 fps video at 1080p at up to 2x speed (the built-in app drops to 480p).

**Phase 0 (this version):** a platform check: launch counter, remote key codes,
playback with speed and seek, and an ad check for Premium.

Remote: OK play/pause · ←/→ seek 10 s · ↑/↓ speed · Red or 1 full screen ·
2 next test video · Back twice exit.

This repo is public (GitHub Pages on the free plan), so it must never contain
secrets or personal data.
